# pos_feu_foret
 Travail de recherche : calculateur de risque par zone géographique, combinant modélisation probabiliste de l’aléa par automate cellulaire, valorisation réaliste de l’enjeu, caractérisation de la vulnérabilité, pour produire, à partir d’un plan ou d’une carte de zone, une cartographie du risque à l’échelle du bâtiment
